# Waypoint — downloads & issues

**Waypoint** is a local-first link keeper for people with too many open tabs. Drag a tab into
your browser's side panel, close it, and find it again by where you work. A small menu-bar app
keeps your links on your Mac — no account, no cloud.

- Website: [vizis.cz/waypoint](https://vizis.cz/waypoint)
- Guide: [vizis.cz/waypoint/docs](https://vizis.cz/waypoint/docs/install)
- Privacy: [vizis.cz/waypoint/privacy](https://vizis.cz/waypoint/privacy)

> This repository hosts the **release downloads** and the public **issue tracker** for Waypoint.
> The source code is not published here.

## Downloads

Every [release](../../releases) carries:

| File | What it is |
|---|---|
| `Waypoint.dmg` | The Mac app (signed and notarized), macOS 13 or newer |
| `waypoint-firefox.xpi` | The extension for Firefox and Zen, signed by Mozilla — open it in the browser to install |
| `waypoint-chromium.zip` | The extension for Chrome, Edge, Brave and Helium, for **Load unpacked** (developer mode) |

The newest files always live at
`https://github.com/vizis-hq/waypoint-releases/releases/latest/download/<file>`.

In normal use, install the browser extension from its store (Chrome Web Store, Edge Add-ons,
Firefox Add-ons) — the links are on the website.

## Reporting a bug

Please [open an issue](../../issues/new/choose). Your Waypoint version and build are shown in
**Settings › General** and in the menu bar menu.

## Privacy

Waypoint has no telemetry — it can't report problems by itself. Please don't post your links or
other personal data in issues.
